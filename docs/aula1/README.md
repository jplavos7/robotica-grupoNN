# Material da aula 1

- `Relatorio_E0_Lite6_3paginas.pdf` e `.docx`: relatório de três páginas, copiado sem alterações.
- `Figure_1.png` e `Figure_2.png`: gráficos incluídos no relatório.
- `notas.md`: notas detalhadas da sessão, copiadas sem alterações.
- `originais/`: os dois scripts tal como foram guardados na aula; contêm o IP da bancada e não são os scripts a executar a partir deste projeto.

As versões integradas estão em `scripts/log_joints.py` e `lite6/session.py`.
Na aula, foram registados no Studio 54°/s para as juntas e 150 mm/s para o TCP
no modo reduzido. Estes valores, o home, o offset da garra e os restantes limites
do projeto devem ser confirmados com o docente antes de usar o robô real. A
fronteira da bancada e a função Python que a aplica continuaram sem validação
experimental. O relatório e as notas conservam esta distinção.
